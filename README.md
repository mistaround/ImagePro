# ImagePro

跨平台桌面看图对比工具，主要用于 AIGC 实验结果横向对比评估和数据集质量筛选。

基于 Electron + React + TypeScript 构建。

## 功能

### 预览模式
- **三栏布局**：左侧边栏（文件夹管理）+ 主区域（图片网格）+ 底部操作栏
- **虚拟滚动网格**：基于 `@tanstack/react-virtual`，支持上万张图片流畅浏览
- **多列切换**：支持 2/4/6/8 列预览，滑块缩放卡片大小
- **多选与批量操作**：点击选中/取消，支持批量复制、移动、删除（系统回收站）
- **文件夹管理**：最多添加 6 个实验文件夹，自动分配颜色，支持别名编辑和拖拽排序
- **收藏路径**：常用文件夹路径收藏，快速添加

### 打标系统
- **四色打标**：红/黄/蓝/绿，键盘 1-4 快速打标，0 清除
- **SQLite 持久化**：标记数据存入 `~/.imagepro/tags.db`，刷新不丢失
- **撤销**：`Cmd+Z` / `Ctrl+Z` 撤销上次打标
- **Tab 跳转**：跳到下一张未标记图片
- **标记统计**：侧边栏显示各颜色标记数量，点击过滤

### 对比模式
- **三栏布局**：左栏（文件夹选择）+ 中栏（对比面板）+ 右栏（图片选择）
- **同名匹配**：勾选后自动找出所有文件夹中同名的图片，点击文件名即可对比
- **独立选图**：取消同名匹配后，每个文件夹独立列表可分别选图
- **自适应布局**：1-3 文件夹单排，4 文件夹 2×2，5-6 文件夹 2×3
- **Peek 对比**：长按其他面板的字母按钮（A-F），将对应图片交换到当前窗口快速比对
- **同步控制**：支持同步缩放（Ctrl+滚轮）和同步滚动
- **原图加载**：对比模式加载全分辨率原图，适合细节对比

### Session 管理
- 保存/恢复工作状态（文件夹列表、别名、颜色、视图模式）
- 数据存储在 SQLite 中

### 导出
- 支持 CSV 格式导出标记结果

## 开发

```bash
npm install
npm run dev      # 启动开发服务器
npm run build    # 生产构建
```

## 技术栈

| 层级 | 技术 |
|------|------|
| 桌面框架 | Electron |
| 前端 | React 18 + TypeScript |
| 构建 | Vite + electron-vite |
| 样式 | Tailwind CSS |
| 状态管理 | Zustand |
| 图片处理 | sharp（缩略图生成） |
| 数据存储 | better-sqlite3 |
| 虚拟列表 | @tanstack/react-virtual |
